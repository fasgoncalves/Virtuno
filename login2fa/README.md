
# login2fa

Sistema de login seguro com autenticação em dois fatores (2FA).

- Logging configurável
- Bloqueio automático após número de tentativas
- Visual noir estilizado
- Cookies de sessão de 12 horas

## Instalação

```bash
pip install .
ou então

cd login2fa
pip3 install -e . --config-settings editable_mode=compat

```
